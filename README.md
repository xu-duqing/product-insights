# 产品心得与收获

每天的产品思考、商业洞察、讨论结论与阶段性收获，统一沉淀在这个仓库。

---

## 仓库用途

这个仓库用于保存我们在讨论过程中形成的：

- 商业结论
- 洞察与判断
- 心得与收获
- 后续待验证的问题
- 可执行动作与决策建议

目标不是做“聊天存档”，而是把分散讨论沉淀成可复用、可回看的知识资产。

---

## 记录原则

每次新增内容，尽量按下面结构整理：

1. 结论（What）
2. 逻辑链路 / 证据（Why）
3. 可执行动作（How）
4. 风险与反证（Risks）
5. 待继续验证的问题（Next Questions）

如果原始输入只是零散聊天片段，也优先整理成结构化笔记后再入库。

---

## 默认工作约定

后续凡是我们讨论出来、值得保留的商业结论 / 心得 / 收获，默认写入这个仓库：

- 新主题：在 `insights/` 下新建对应笔记
- 已有主题补充：直接更新对应笔记
- 完成后：直接 `commit` 并 `push`

也就是说，这个仓库就是后续商业洞察沉淀的默认落点。

---

## 提交规范

建议使用清晰、简短、可检索的 commit message，例如：

- `docs: add board thread business insights`
- `docs: update product insight notes`
- `docs: refine saas opportunity takeaways`
